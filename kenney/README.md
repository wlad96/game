# Модели Kenney для карты Рио

Исходные модели, из которых собирается Рио. Игра их напрямую не грузит —
нужные файлы отбираются, сжимаются и копируются в `public/models/`.

| Папка | Пак с kenney.nl |
|---|---|
| `roads/` | City Kit (Roads) — обязательно |
| `cars/` | Car Kit |
| `nature/` | Nature Kit |
| `boats/` | Watercraft Pack |
| `suburban/` | City Kit (Suburban) — по желанию |
| `characters/` | Mini Characters — по желанию |
| `pirate/` | Pirate Kit — по желанию |
| `other/` | всё остальное |

Из каждого пака нужна только папка `Models/GLB format` (`.glb` + `Textures`).
