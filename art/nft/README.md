# Арт для игры

- `nft/` — картинки NFT для галереи (PNG/JPG/WEBP, любое количество).
  Имя файла станет подписью: `001 Sai Astronaut.png` → «Sai Astronaut» (номер в начале задаёт порядок).
- `portals/` — картинки порталов городов: `rio.png` (или .jpg/.webp). Позже: `buenos-aires`, `lima`, `santiago`, `bogota`.

Исходники могут быть большими — для игры они уменьшаются и сжимаются в `src/assets/`.
