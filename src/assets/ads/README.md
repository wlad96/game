# Реклама в Рио

Картинка рекламодателя: `<код места>.webp` (или .png/.jpg) в этой папке, например `R-1.webp`.
Текст карточки (по E): `src/data/ads.json` → `ads.<код>`: advertiser, title, text, url, promo.
Контакты для свободных мест: `src/data/ads.json` → `contact` (email, telegram, site).
